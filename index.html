Embedded Bit Manipulation Principles

Firmware Applications

1. Hardware Control Flags & Status Registers

Microcontroller CPU status registers (e.g. SREG or CCR) use single bit positions for zero (Z), negative (N), overflow (V), and carry (C) flags. Bit shifts enable fast bitwise testing without branch overhead.

2. Efficient Arithmetic by Powers of Two

Logical Left Shift by $n$ computes $x \times 2^n$. Arithmetic Right Shift computes $\lfloor x / 2^n \rfloor$ while maintaining the signed two's complement value without invoking an expensive ALU multiplier hardware cycle.

3. GPIO Pin Masking in C / Assembly

Embedded C code uses bitwise shifts to target specific peripheral pins:

// Set Pin 3 High without altering other pins
PORTB |= (1 << 3);

// Clear Pin 3 Low
PORTB &= ~(1 << 3);

// Shift chaser pattern left
PORTB = (PORTB << 1) | (PORTB >> 7);

Computer Organization & Architecture: Barrel Shifter Theory

1. What is a Barrel Shifter?

A barrel shifter is a combinational logic circuit capable of shifting or rotating a computer data word by a specified number of bits in a single clock cycle, regardless of shift amount. In contrast to sequential shift registers that require n clock cycles for an n-bit shift, a barrel shifter uses multiplexer stages to execute shifts in $O(1)$ clock cycles ($O(\log_2 N)$ gate propagation delay).

2. Architecture of the 3-Stage Logarithmic Barrel Shifter

For an 8-bit word ($N = 8$), the shift count $k$ ($0 \le k \le 7$) is represented as a 3-bit binary integer $S = (S_2 S_1 S_0)_2$ where $k = 4 \cdot S_2 + 2 \cdot S_1 + 1 \cdot S_0$.

Stage Control Signal Action When Sn = 0 Action When Sn = 1
Stage 0 S₀ (Bit 0) Pass through unchanged (Shift 0) Shift by 1 bit position (20)
Stage 1 S₁ (Bit 1) Pass through unchanged (Shift 0) Shift by 2 bits position (21)
Stage 2 S₂ (Bit 2) Pass through unchanged (Shift 0) Shift by 4 bits position (22)

3. Summary of Bit Operations

  • LSL (Logical Shift Left): Bits move left towards MSB. Discarded MSB bits are lost. 0 is padded into LSB.
  • LSR (Logical Shift Right): Bits move right towards LSB. Discarded LSB bits are lost. 0 is padded into MSB.
  • ASR (Arithmetic Shift Right): Bits move right. The sign bit (MSB, Bit 7) is copied into all newly opened positions to preserve negative two's-complement numbers.
  • ROL (Rotate Left): Bits rotated off the MSB wrap around to fill vacated LSB positions; no bits are lost.
  • ROR (Rotate Right): Bits rotated off the LSB wrap around to fill vacated MSB positions; no bits are lost.
